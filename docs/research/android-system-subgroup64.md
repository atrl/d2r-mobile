# vivo system driver subgroup mismatch

The user-supplied preview.10 report identifies vivo V2436A / Android 16 API 36, Adreno 750 Qualcomm driver, physical/default shader subgroup64, and a subgroup32 resource package. Native termination: `FATAL Vulkan shader subgroup profile 32 differs from selected shader execution 64; rebuild for the actual policy`. Android reports native crash reason5/status6. This proves the immediate abort, not absence of further compatibility problems. Turnip was suggested as a short-term alternative, but the user reports another crash without a new report yet.

Provide a separate translated subgroup64 cache with 6931 keys matching subgroup32. The 32-lane guest warp semantics remain handled by the existing Ryujinx translator's host subgroup adaptation. Do not relabel or bypass profile checks. All 6931 SPIR-V modules pass spirv-val for Vulkan1.1. The patch ships only .spv/.meta files plus two profile files: 13864 entries, 465582652 expanded bytes, 142166085 compressed bytes, SHA256 `98078bfa0f0c25f23c9a10e5be48ee356e5e937937a76392544fc38d99c2a796`. Immutable asset: release data-shaders64-v1, d2r-shaders64-v1.zip.

The launcher uses existing SHA-pinned resumable download with retries, then bounded flat-path extraction into a staging folder, validates file pairs/profile/count and atomically renames to shaders/subgroup64. The base cache, ROMFS and saves remain untouched. Successful installation selects the system driver. Runtime selects the separate variant only when effective shader execution is64 and the base profile differs; missing or mismatching variant profiles fail clearly. The pipeline disk namespace already includes effective subgroup size.

Tests: 22 Linux checks pass, including actual native selector extraction and archive traversal/incomplete-publication regressions. Real converted patch extraction is checked separately. Device gameplay after this change is not yet verified on vivo; the next report must show subgroup64 matching, then evidence of reaching character selection and entering gameplay.
